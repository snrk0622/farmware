## 1. 製品表示への統一

`ChunkTilemapPresenter`から、旧Biome Tile配列、一体型Ground／Wall、仮液体、淡水の代用Tile、旧共有Tilemapへの切替、旧原点の遅延消去を削除した。製品41材質と液体3種のカタログ、上面・断面・液体・反射の必須参照が揃わなければ、理由を1回だけ通知して描画を開始しない。

採用済みチャンク別Tilemapの部分反映、空セル書込省略、消去完了後のプール再利用、自動Floating Originでの位置更新を維持する。旧共有方式の再構築用だった岩壁影の再採用待ち集合も削除し、現在のチャンク表示寿命で直接管理する。

Scene構築メニューは`Build Map Prototype`へ改称した。保存後の検査にも残っていた水中レイヤーの旧Sorting Layer条件を、採用済みの`WaterSurface`へ合わせた。現行の仮資源3アイコンだけを生成し、地形・液体は製品公開処理と接続処理を使う。ビルド前処理も製品Atlasの公開だけを実行し、旧土地・岩壁Atlasを再生成しない。

旧地形のPNG／Tile、旧`Terrain/Base`素材、旧土地・岩壁Atlas、専用テストと各metaを削除した。製品41材質、製品液体、水面・発光の調整値、仮資源アイコンは維持する。SampleSceneの差分は旧Inspectorフィールド24行の削除だけであり、CameraのViewport等の保存時差分は戻した。製品公開処理の再実行で更新された41材質の生成Fingerprint記録も含める。設定アセットの差分はこの記録だけで、材質入力や暗色化係数は変更していない。

## 2. 可視範囲の投影寸法

Cameraの要求範囲に、旧一体型の12px Wall／8px Ground断面が残っていた。製品の上向き2タイル（Wall上面）と下向き3タイル（Ground崖面）を共通投影定数から取得するよう修正した。

接地点が画面外でも投影が届く地形を読み込むための範囲であり、先読み設定を広げる対策とは異なる。生成2、先読み1、表示予算4、プール8、速度12／36の製品設定は変更していない。正負のチャンク境界で2段／3段全体を含めるPlayMode回帰を追加した。

## 3. Map ViewerのWorld固有Runtime ID

実製品WorldとMap Viewerを実際に照合した際、実WorldのGrassLoam Ground IDが3、Wall IDが4で、診断側ではそれぞれ2、3となることを確認した。定義GUID順の添字であるRuntime IDは、動物などの定義が加わると変わる。従来は数値をそのままSnapshotへコピーしたため、編集差分が`InvalidDelta`として拒否される場合があった。

Snapshotのコピー時に、実WorldのRuntime ID→定義GUID→診断側Runtime IDを解決する。区画の定義分類を照合し、要求中は解決結果を再利用する。明示除去のInvalidは維持し、未知定義や分類違いを別素材へ読み替えない。SnapshotへBlobやECS参照は残さず、元Worldの差分も変更しない。

Map ViewerのHoverのRuntime IDは診断カタログ内の値である。ゲーム側との材質同一性は安定材質ID・定義GUIDで比較する。追加定義でIDをずらしたWorldから負座標の差分を取得し、サンプラーまで通す回帰を追加した。
