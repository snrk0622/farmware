# 地形表示・Map Viewerの遅延調査

- 記録日: 2026-10-28
- 対象: TERRAIN-01C6-D5。項目全体の完了記録ではない。
- 基準commit: `b05e817f`。生成規則、GeneratorVersion、製品の先読み設定は変更しない。

## 1. 結論と今回の変更

通常カメラ移動の遅れとMap Viewerの待ちは別の原因だった。それぞれを次の順に変更した。

1. **通常表示の依存範囲**: 中心チャンクが完成していても周囲8チャンクの完成まで表示を始めていなかった。描画に必要な入力が揃った16×16サブチャンクから反映する方式へ変更した。部分表示に加えて可視辺の入力を角より先に生成するようにし、最終の30秒移動で可視サブチャンク未反映は9,916フレームすべて0だった。先読み1・同時生成2・反映予算4を維持し、生成・保持数と動物初期化範囲を増やさない。
2. **Map Viewerの再表示**: Window単位・最大32チャンクの完成自然地形をManaged値コピーで保持し、重複範囲の再生成を避ける。最新の地形差分は要求ごとに別Snapshotから適用する。
3. **Map Viewerの初回生成**: 未訪問チャンクを既存製品のBurst Jobで生成する。専用Editor Worldだけへ1件ずつ投入し、未完了中はEditorへ制御を返す。同じ1チャンクの初回は約12秒から約1.6秒となった。製品World・固定Tick・動物初期化へ接続しない。

通常表示改善は人間確認を受け、Development Buildでの通常・高速の局所計測も第8章で完了した。高速の継続移動、全表示条件の一致、正式な最大Viewport・対象機器の性能保証とは分離する。D5の完了チェックは付けず、D6へ移らない。

## 7. 人間確認と残件の扱い

2026-10-28、ユーザーから「かなり改善された」と通常表示の改善確認を受けた。一方、Gameビューの初期描画にはまだ待ちがあり、診断Cameraの高速移動では少し描画遅延が残るとの報告を受けた。F4・全境界・全条件の確認完了や、D5全体の性能合格を意味しない。

- **初期描画**: 新規開始・保存再開時に必要な準備時間として、UI-01Bの開始・再開導線でロード中表示と操作開始条件を設計する。ロード画面自体は生成時間を短縮しないため、初期スポーン／保存位置、可視地形と判定に必要な入力が揃うまで操作開始を待つ方針を検討する。既訪問地形の再構築と新規生成、資源・個体群の復元は区別して時間とメモリを測り、待ち時間が長すぎる場合は処理側も改善する。現段階でロード時間の合格値やロードUIの実装済み扱いを置かない。
- **通常移動の想定**: 製品プレイヤーの徒歩は現在の診断Cameraの通常12タイル/秒より遅い想定とユーザーから共有された。具体的な歩行速度は未確定とし、Cameraの比較条件や製品設定を今回変更しない。

### 計測方法

一時計測Componentは専用起動引数があるDevelopment Playerだけへ生成した。Camera入力後・Observer前に通常の`SetWorldPosition`で移動し、全Update後のLateUpdateで完成ECSとPresenterの表示Maskを照合した。比較元の部分進捗は行優先の反映件数からMaskへ復元した。Cameraの矩形とWall投影分に交差する16×16領域の未反映を数え、画面欠けの画素数とは区別する。

行・GPU行を各20,000件の配列へ事前確保し、CSV・画像・文字列の出力は区間終了後に行った。非公開Dictionaryの読取口は初期化時だけExpressionから型付きDelegateへコンパイルし、毎フレームのboxingを避けた。計測ループ自身のMain Thread managed allocationは全4ケースで0 byteだった。Recorder値は直前完了フレーム、地形状態は観測フレームなので、同じ行の原因・結果とは断定しない。

GPUとCPU Main/RenderはFrameTimingManagerを用い、元フレーム開始timestampで重複を除いた。非同期配送の影響を抑えるためGPU統計は移動区間の前後1秒を外した6〜34秒だけで集計した。`Render Thread`のProfilerRecorderは未対応だったため-1を保存し、Render時間はFrameTimingManager値を使った。CPUの`Main Thread` Recorderは60fps待機を含み、地形処理時間とは別に扱う。メモリはUnityの使用・予約・managed・Gfx Counterを55秒の全区間で記録した。OS RSSは1秒間隔でプロセス全体を観測し、起動・終了時のCSV/画像出力も含む参考値とする。
