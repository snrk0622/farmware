# TERRAIN-01C2 地質基盤 実装記録

- 更新日: 2026-10-20
- 対象PR: TERRAIN-01C2-A（PR #32、developへマージ済み）、TERRAIN-01C2-B
- 状態: C2-B実装・AI確認・人間による表示確認完了

## 1. この変更単位の範囲

TERRAIN-01C1の連続環境軸へ、Biome、Block、資源から独立した固定の卓越基盤地質を追加する。変更量と分布確認を分けるため、次の2PRへ分割した。C2-AはPR #32としてdevelopへマージ済みであり、C2-Bはそのdevelopから独立ブランチを作って実装する。

- C2-A: 8分類の安定ID、固定Definition、基礎特性、標高別出現重み、512タイル地域の純粋生成、用途別Salt、ECS Buffer、状態ハッシュ、Definition・負座標・境界テスト。
- C2-B: 複数Seedの面積比・連結領域・境界・孤立領域・環境クロス集計、GameビューのDebug Visualization、Map Viewer、凡例、中央・Hover情報、表示テスト。

C2-A／Bでは現行7Biome、Ground、Wall、水域、資源配置を置き換えない。水文、地下水、最終18Biome、地質別Blockパレット、資源適合はTERRAIN-01C3〜C7へ残す。C2-Bの人間確認まで完了したため、本変更のcommitをもってロードマップのTERRAIN-01C2を完了扱いにする。

## 2. 固定Definition

`GeologyClass`は`None = 0`を予約し、未固結堆積物、砂岩、石灰岩、泥岩・頁岩・粘板岩、花崗岩質岩、変成岩、火山岩、超苦鉄質岩を1〜8の安定IDで持つ。各Definitionは次を保持する。

- 0〜65,535の透水性、地下水保持力、侵食抵抗。
- 石灰岩だけの`SupportsKarst`、火山岩だけの`SupportsActiveVolcanism`。
- 全8分類で合計10,000の基礎重み。
- 海面下、低地、平地・台地、山地、高山ごとの、256を1倍とする固定小数倍率。

Definition検証は、8分類が重複なく揃うこと、固定生成寸法、既知フラグと分類ごとの必須フラグ、基礎重み合計、全標高区分の正の補正後合計を確認する。不正値を暗黙補正せず生成失敗にする。Definition配列の位置をIDや抽選順に使わず、抽選時に管理ヒープを確保しない`FixedList`へ安定ID順で正規化する。

## 3. 地質地域の生成

絶対整数タイル座標を地質専用のX・Y Saltで256／128タイル、相対比重2：1の2オクターブワープへ通し、各軸最大64タイルの変位を加える。ワープ後座標を床方向除算で512タイルのマクロセルへ変換する。負座標でもC#の0方向丸めを使わない。

各マクロセルの中心には、X・Y別Saltで`-192〜+191`タイルのジッターを加えたサイトを1個置く。対象セルの前後2セル、計5×5の25サイトを省略せず、64bitの平方距離で最近傍を選ぶ。完全同距離ではSiteX、SiteY、MacroCellX、MacroCellYの昇順で決め、列挙順やJob順へ依存しない。

支配サイトの絶対SiteX・SiteYで標高を再評価し、その標高区分の補正後重みを64bit整数で求める。クラス選択専用Saltの64bit値を拒否法で偏りのない有界整数へ変換し、安定ID順の累積区間から1分類を選ぶ。同じサイト座標では毎回同じ分類になるため、タイル座標、Biome、火山活動度、水文、資源、実行時刻、共有乱数状態を抽選へ混ぜない。

Chunk生成Jobとチャンク状態ハッシュでは、64×64タイルと各軸±64タイルのワープから候補になり得る最大6×6サイトをJobローカルの`FixedList4096Bytes`へ一度だけ生成する。各タイルでは固有のワープ後座標に対する5×5候補だけを絞り込み、距離と同点順を省略しない。サイトキャッシュは管理ヒープ、ECS、セーブへ保持せず、単一タイルAPIはキャッシュなしでも同じ純粋結果を返す。

## 4. ECS結果と移行境界

`GeneratedTile`へ地質分類、必須条件フラグ、透水性、地下水保持力、侵食抵抗をコピーし、チャンク状態ハッシュへ全値を含める。`WorldGenerationAuthoring`は既存Inspector値から設定Snapshotを作る際に共有の固定地質既定値を追加し、既存Sceneの未初期化値で全生成が失敗しないようにする。生成設定不正、Warp後座標または候補サイトが`int`範囲外の場合は`TryGenerateTile`が`false`を返し、チャンクJobは部分結果を公開しない。

地質は採掘や配置で書き換わらない固定生成結果とする。Presentation、Tilemap、Sprite、表示名、最上面Blockから地質を逆算せず、後続の水文・Biome・資源はSimulationの確定Bufferを参照する。C2-Bの診断表示も確定結果または同じ純粋Generatorを読み、既存`Biome`、`Terrain`、`Volcanic Activity Potential`表示へ地質色を暗黙に合成しない。

## 5. C2-Bの分布監査と診断表示

`Farmware > World Generation > Analyze Geology Distribution`は、既存分布監査と同じ既定3シード、32タイル間隔、129×129代表格子をバックグラウンドで生成する。シード同士は接続せず、地質別の代表サンプル数・比率、4近傍連結領域数、1サンプル孤立領域数、最大概算面積、外接矩形対角による最大概算直径、異種境界の概算長を集計する。標高区分、現行Biome、火山活動度5段階とのクロス件数と、走査順を含む比較署名も出力する。

面積、直径、境界長は代表格子から求める比較用の概算値であり、実タイルを全数走査した厳密値ではない。現段階では任意の合否閾値を設定せず、調整前後の同条件比較と目視確認に使用する。

Gameビューの`Debug Visualization > Geology`とMap Viewerへ、次を個別モードとして追加する。

- 8分類の`GeologyClass`。
- 0〜65,535の透水性、地下水保持力、侵食抵抗。
- カルスト適性、活動的火山適性のDefinitionフラグ。
- 支配サイト。マクロセル座標から安定色を作り、同じサイト内では同色にする。凡例の2色は座標由来色の例であり、実際の地図には凡例と異なる色も表示される。
- 支配サイト境界。Gameビューは上下左右の隣接1タイル、Map Viewerは広域縮小でも見えるよう上下左右の隣接代表サンプルとの相違を表示する。

中央HUDとMap ViewerのHoverには、地質分類、フラグ、3基礎特性、支配マクロセル、サイト絶対座標、サイトまでの平方距離を表示する。表示はSimulationや生成設定を変更せず、サイト診断が必要なモードだけ追加の地質生成を行う。
